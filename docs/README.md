## 维护规则

一个事实只在一处定义，其余引用。改错地方比不写更贵。

| 变更 | 同步到 |
| --- | --- |
| 新增或改名领域概念 | design.md 附录 A，并清理代码中的旧称 |
| 改动选型、表结构、不变量 | decisions.md 新增一条，含「重新评估条件」 |
| 改动启动入口、迁移方式、故障处置 | runbook.md |
| 接口字段或错误码变化 | 生成的 OpenAPI + 面向调用方的变更记录 |
