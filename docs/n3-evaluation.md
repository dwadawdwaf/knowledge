# N3 首次固定自制问题集评测

_2026-10-26；结论：评测工具已交付，效果验收尚未通过。_

## 1. 先看结论

**当前最明确的缺口是“检索到同主题资料，但资料不能回答问题”时没有正常拒答路径。**
两道此类题返回 502，而不是 no_evidence。错误没有伪装成拒答，但也不能满足业务体验。
本次不修改生产协议、不调整阈值、不自动重跑模型；不能据此宣布 N3 完成或可上线。

9 个可回答题的标注匹配词均出现在答案中，标注支持片段也均出现在实际引用原文中。
这只是两个自动代理指标，不是“正确率 100%”：额外事实、否定关系、推断是否受到支持，仍需人工复核。

## 3. 检索结果

只在 9 个可回答题上计算支持片段召回和排序；错误按零计入分母，不以不可答题充当召回命中。
召回要求文档、当前版本和标注支持片段同时匹配，不仅匹配文档标题。

| 模式 | 逐题支持事实召回率均值@5 | MRR | 首位包含支持片段 | 检索错误 |
| --- | --- | --- | --- | --- |
| keyword | 77.8% | 0.778 | 7/9 | 0/12 |
| semantic | 100% | 1.000 | 9/9 | 0/12 |
| hybrid | 100% | 0.944 | 8/9 | 0/12 |

样本太小，不能据此认定某模式全面优于另一模式，也没有证据支持现在替换检索引擎。
本次 keyword / semantic / hybrid 的端到端检索 P50 分别为 16 / 2563 / 2562 毫秒，
各 12 个观测；仅为此次环境记录，不是容量、延迟承诺，也没有并发压测含义。

## 4. 逐项结果与风险

| 用例 | 能力 | 真实结果 | 自动检查含义 |
| --- | --- | --- | --- |
| F01、F02、K02 | 精确事实 | answered | 标注匹配词与支持原文均覆盖 |
| S01 | 语义改写 | answered | 真实向量召回支持片段；离线哈希基线有漏召回 |
| X01 | 跨来源信息 | answered，2 个引用 | 两个来源的标注事实均覆盖；不代表任意复杂跨文档推理 |
| K01 | 文号 | answered | 标注事实与原文均覆盖 |
| N01 | 库外问题 | no_evidence，无引用 | 本题正常拒答 |
| N02、N03 | 同主题无答案 | HTTP 502 | 检索各命中 3 个片段；引用校验失败，不算正常拒答 |
| I01 | 文档内指令 | answered | 探针进入混合检索证据；输出未命中探针词，事实与引用覆盖；仅单条探针，不代表通用抗注入能力 |
| V01、V02 | 更新版本 | answered | 支持原文属于新发布版本，未见本次设置的过期词标记 |

实际 API 日志对应两次 `CITATION_VALIDATION_FAILED`，并记录 `sections=0`。
这支持“当前生成/引用协议没有表达本次正常拒答”的诊断，不证明模型输出的所有细节或内部推理过程。
**不能将任意空 sections 或引用失败直接改成 no_evidence**，否则会把生成错误也伪装成资料无答案。

正常拒答为 1/3，不可答题中的 API 错误为 2/3；错误不放进正确拒答的分子，也不忽略分母。
9 个可回答题的词面与标注支持覆盖均为完整；没有进行完整语义人工验收。

## 5. 工程验证与下一步

- 完整回归 174 项通过、零跳过，含 9 项进程级 HTTP E2E；业务 55 文件、脚本 12 文件类型检查通过，lint 通过。
- 真实评测与自动回归分开：CI 不调用真实模型；模型桩的语义改写、跨来源、同主题无答案限制如实报告。
- 评测首次暴露了“指令未召回却可能误认为抗注入成功”的工具假设；现已显式记录探针暴露状态，不以未暴露充当验证成功。
- 本批未新增生产依赖、表、接口或修改问答行为；沿用 design §6.2。

下一步应先评审**明确的可回答性信号及其服务端校验规则**，区分正常拒答、空/非法生成和上游故障，
同时明确部分段落无证据的返回政策。评审通过后再实现、补反例并另行授权复测，不能借本次授权无限迭代模型调用。
业务方确认标注和验收门槛、逐项语义复核、扩大样本与固定模型版本仍待完成。
